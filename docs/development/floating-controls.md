# 原生悬浮控制

2026-11-16。属于 M1 平台适配及 M4 联验的一部分，不表示首期或真实游戏闭环已经完成。

## 已确认行为

- 授权无障碍后默认显示。设置可关闭；用户选择持久保存，重新授权不会把已关闭的选择改回开启。
- 球 → 快捷控制 → 常用列表，复杂配置回主 App。任务列表右侧星标切换常用，没有独立收藏管理流程。
- 当前项直接读唯一执行器快照；短按暂停，长按停止且不再触发短按。暂停保留全队列接管状态；继续与重新开始作用于当前任务。
- 常用行右侧加入队列，已排队禁用；当前项由面板顶部控制，不重复列出。候选变化不会移除当前项的控制。
- 回到主 App 隐藏窗口，离开后按显示设置恢复；隐藏窗口不暂停、停止或重启任务。
- 拖动结束保存位置，横竖屏分别记忆；展开面板按实际屏幕及系统栏可用区域布局。

## 所有者与数据流

`AssistApplication` 持有唯一 `ExecutionRuntime` 及 `FloatingPreferences`。任务列表与浮层共用稳定的目标／任务身份；DataStore 只存显示、常用及位置，不复制任务 JSON、配置或运行状态。

`GameAccessibilityService` 连接后创建 `FloatingOverlayWindow`，断开时销毁。窗口使用 `TYPE_ACCESSIBILITY_OVERLAY` 和自己的 Compose 生命周期；没有另申请普通悬浮窗权限，也没有第二个执行器。Activity 可见性只影响窗口显示。

`floatingTasks` 合并已启用版本、常用偏好、配置失效通知及运行环境变化，调用只读 `assessStart`。读取错误／条件未确认与明确不可执行分开表达，实际提交仍重新核对版本、配置及上下文。当前 APK 只为完整已知的 `control.wait` 程序证明无需画面观察；需要游戏观察的动作尚未注册，不能据此宣称已实现游戏界面过滤。

返回助手保留原页面；点击任务名打开其配置。Intent 只携带导航身份，不能提交任务或授予执行权限。已处理的导航请求保存在 Activity 状态中，旋转不会重复打开已退出的配置页。

## 截图与输入遮挡

截图前临时隐藏本窗口，跨过两个显示帧后请求系统截图；完成、拒绝和取消路径释放排除租约。自动手势与窗口矩形相交时也排除窗口，避免点击被助手自身消费。窗口失败只影响显示，不改变业务执行结果。

手势的排除租约在实际派发后归在途手势所有。取消工作协程不能提早恢复窗口，也不能证明输入静默；只按独立的平台终态释放。撤权／无终态仍保留未确认，不补造成功或静默。输入未确认导致排除租约保留时，用户仍可从桌面进入助手；不承诺该故障下浮层始终可见。

两个显示帧是当前实现的屏幕同步边界，像素及触摸测试只证明已测 API 36 ARM64 模拟器；不能推广为所有设备的合成器时序保证。窗口使用屏幕左上原点，与原始触摸／截图坐标一致，文字仍跟随主题及内容布局。

## 验证及限制

证据集中在 [floating/](build-evidence/floating/README.md)，包括实际窗口／系统截图／受控输入、同一 SQLite 运行器、偏好重开、主题横竖屏、常用星标、版本变化及完整回归。所有输入只到自有蓝色触摸夹具，没有游戏操作，也没有把示例任务写进正式任务库。

设备测试发现并修复了常用列表自定义键无法存入 Android Bundle 的崩溃。主题检查还补上了独立窗口缺失的内容文字颜色；截图必须等待真实测量和绘制，不能用切层请求刚返回的画面充当最终外观证据。

计划编辑及持久化尚未交付，因此本轮只有任务常用，不伪造计划收藏。游戏观察、正式动作、完整资源包、通知、后台保活及 24 小时验证仍未完成。服务重连和显示偏好不等于应用开机自启或系统杀进程后的长期可靠运行。
