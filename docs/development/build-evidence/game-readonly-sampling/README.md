# 游戏物资页面只读采样

2026-11-17，基于 `788768e`。用户明确允许真机只读导航和本地截图，范围不含领取、购买、强化或发消息。本轮未改生产源码、任务语法、模型或阈值；操作来自人工逐帧核对后的 ADB 导航，不是正式 App 自动任务。

说明数字是本次版本界面观察，不是新增 App 默认、计时规则或自动购买策略。商店首次弹出可选式神模型扩展包下载提示，选择取消；没有确认下载。礼包页返回先进入商店地图，再返回庭院，不能假定一次返回已到庭院。

每日礼包可作为首个代表领取任务的候选。制作任务仍需把“每日礼包”与其“领取”目标关联，区分相邻付费商品，观察领取后和已领取状态，并验证结果未知时的核对与恢复。当前没有制作／安装／发布该任务，也没有点击任何领取、价格、购买或兑换按钮；未进行强化、消息发送或账号快照。

## 静态离线 OCR

固定现有 MaaFramework 5.16.1 和转换后的 PP-OCRv6 small 模型，在无网络权限、未绑定控制器的独立探针中处理两张本轮原始真机截图。实际推理在 API36 ARM64 专用模拟器进行，本轮没有在手机安装探针或通过探针操作游戏。

| 同一原图及人工标注 | 整图 | 人工选定局部区域 |
| --- | --- | --- |
| 日常礼包：每日礼包、领取、每日优惠礼包、每日符咒包 | 4/4 | 4/4 |
| 杂货铺：永久勾玉卡、售罄 | 2/2 | 2/2 |

各三次结果一致，原始 OCR 中六处文字也均为字面一致。指标沿用探针的忽略空白、文字一致且框有交集的一对一匹配；不是严格边框精度或整图误报率。两张原图、六处人工标注，没有独立复核；区域与重复次数不增加样本量，没有跨主题留出集。人工区域只用于实验，未写入生产坐标或任务资源。

[ocr-test.txt](ocr-test.txt) 为一次既有 instrumentation 用例通过，另包含明／暗／空白合成对照；不应将用例通过理解为所有游戏场景通过。[verification.json](verification.json) 保留脱敏观察、输入摘要、模型和产物摘要、逐次命中数与清理结果。Gradle 首次在沙箱内因本地锁 Socket 权限失败，随后获准离线构建成功，未改变代码或检查项。

所有含账号、资源余额或动态广播的原始截图、标注、导航日志和完整 OCR 只留在忽略目录。私人测试输入打包字节与原图一致；原有四个测试资源已逐路径／摘要恢复。模拟器测试 APK 和本轮私人输出已清理，原探针主包及其他数据保留，正式助手已重开。手机游戏最终在庭院，用户授权及未点击的领取机会保留。

这是当前页面和静态识别证据，尚未通过正式 App 的截图→版本资源→工作器→执行器链路。领取授权、任务控制流实施策略、结果核对、已领／无资格样本与留出主题仍需补齐，M3／M4 不据此通过。
