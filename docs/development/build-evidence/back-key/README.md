# 游戏内返回键观察与每日礼包状态

2026-11-18，基于 `6edb63c`，SM-G9910／API35，官服客户端 2.8.88／引擎 2.8.89。用户批准游戏内验证；本轮不领取、不购买、不下载。操作为人工逐帧核对的 ADB 输入，不是正式 App 执行器。私人截图与导航记录只保存在忽略目录。

## 观察

1. 启动游戏，进入庭院，打开菜单进入商店，商店弹出“式神模型扩展包下载（5278MB）”对话框。
2. 在该对话框上发送一次系统返回键（`KEYCODE_BACK`，系统层与无障碍 `GLOBAL_ACTION_BACK` 相同的按键事件）。**游戏没有关闭这个对话框，而是弹出系统风格的“确定退出阴阳师？”（取消／退出）。**
3. 点击“取消”后回到下载对话框；再点击下载对话框的“取消”，进入商店。没有再次发送返回键。
4. 进入礼包屋 → 日常：每日礼包卡片按钮再次显示“领取”，说明 11-17 领取后已刷新为可领取。按钮区域与 11-17 领取前截图逐像素相同；卡片图片区不同（倒计时文字由 47 天变为 46 天）。本帧 SHA-256 `0c806260d2a314492c6324cda36d4d1d7e446009aceece141ca4f222831c5d74`。

## 结论

- 在本游戏中，**系统返回键不会关闭游戏内弹窗**：至少在这个对话框上，它会触发游戏的退出确认。若在退出确认上再按一次返回键或误点“退出”，就有退出游戏的风险。`screen.back` 不能用来关闭奖励弹窗或其他游戏内对话框；任务作者不应在游戏界面使用它，除非已在具体画面上观察过它的效果。
- 关闭奖励弹窗仍需要“点击弹窗外空白处”一类的输入，现有动作还不支持（点击只针对识别到的文字目标）。
- 这只是一个对话框上的单次观察，没有覆盖其他弹窗。
