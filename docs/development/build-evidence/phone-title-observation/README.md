# 真机标题页离线 OCR 对照

2026-11-17，源码基线 `8adca13`，本轮未改生产代码、探针源码、模型或识别阈值。真机重新在线后，保留数据更新助手；实际安装 SHA-256 与该基线构建一致，无障碍服务处于绑定状态。官服 2.8.89（261014）在 SM-G9910／API35 正常显示标题页；没有进入庭院或发送游戏输入。

## 对照和结果

同一张 ADB 获取的 2400×1080 私人截图，人工标注七处公共按钮文字。固定 MaaFramework 5.16.1、转换后的 PP-OCRv6 small 模型，在无网络权限、未绑定控制器的独立探针中处理整图和人工选定的菜单区域 `[2140,315,2350,660]`。区域取自同一原图，不另算样本。

| 实际推理环境 | 整图七处标注 | 同一菜单三处：整图 | 同一菜单三处：局部区域 |
| --- | --- | --- | --- |
| API36 ARM64 专用模拟器 | 5/7 | 1/3 | 3/3 |
| SM-G9910／API35／ARM64 真机 | 5/7 | 1/3 | 3/3 |

每项重复三次，结果一致；重复次数不增加覆盖量。整图遗漏“用户中心”“账号”，局部区域两者恢复；“反馈”两种输入都命中。指标沿用探针的忽略空白、文字一致且框有交集的一对一匹配；另核对这三处菜单文字在原始 `detail.all` 中为字面一致，未提交其余 OCR 文本。七处仅为部分人工标注，不计算整图精确率或误报率。

结果支持继续验证局部识别，但局部输入同时改变文字尺度与背景上下文，不能单独归因于缩放，也没有证明换主题后可靠。区域并非生产坐标或默认规则。
