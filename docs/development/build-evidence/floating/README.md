## 故障与修复证据

1. 常用列表最初用自定义 `TaskAddress` 作为 LazyColumn 键，打开时因不能写入 Android Bundle 崩溃。`list-key-before.txt` 保留实际崩溃；改成稳定 JSON 字符串身份后，同一三层场景通过。该早期构建未保留完整 APK 摘要，不宣称可以由此重建原故障二进制。
2. `rotation-before.txt` 记录稳定复现的横屏宽度断言：期望约 1129 px，实际只有 840 px。WindowManager 原来沿用上一层测量宽度；现按当前层明确设置窗口宽度并共享 Compose 尺寸。相同尺寸断言、旋转独立锚点和实际截图通过。
3. `nested-before-tests.txt` 与 `nested-before-artifacts.json` 记录修复前的并发排除失败。第一个请求隐藏后，后续请求因窗口不可见而取得空租约，导致第一份租约释放时提前显示。每份请求现在各自拥有排除计数；隐藏状态只免去显示帧等待，不免除租约。同一原生窗口断言在最终批次通过。
4. 独立浮层缺少内容颜色继承，深色出现黑字；补上 Material 主题内容色。原生截图已实际查看。旋转动画中的短暂取图不作为最终外观截图；最终图同时记录静止窗口及控件坐标。

## 截图及实际边界

`screens/` 仅含蓝色自有触摸夹具和测试等待任务，不含游戏、账号或私人 OCR 画面。浅色竖屏与深色横屏面板已视觉检查，右侧控制及底部入口完整。几何记录用于区别静止窗口与旋转动画中的取图。

当前生产动作只有 `control.wait`；常用候选的无观察证明仅适用于这类完整已知程序。尚未交付计划收藏、真实游戏场景过滤、代表领取任务、前台服务保活及 24 小时验证。两个显示帧的排除实现仅有已测模拟器证据，不保证其他 Android 合成器、Root 环境或 Windows 模拟器的行为。未触发 CI、Release 或部署。
