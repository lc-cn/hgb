# 每日礼包完整实测运行手册（2026-11-19）

用户已于 2026-11-18 批准：每日免费礼包刷新后，在真机官服当前账号上用助手正式动作链跑一次完整流程。范围仅限下文；不含付费、其他礼包、Release 发布或系统设置改动。

## 执行方式

调试构建中的 `LocalTaskTrigger`（仅 debug 变体，`android.permission.DUMP` 保护）在已运行的助手进程内执行本地暂存的任务包，使用独立的临时库。**不使用 instrumentation**，因为它会结束助手进程并使无障碍服务进入崩溃状态。任务包由 `tools/qa/stage_daily_gift_draft.py` 生成在 `.local/debug-task/daily-gift/`（私人内容，不提交）。

## 前置检查（任一不满足就停止并询问用户）

1. `adb devices` 中可见手机，`dumpsys accessibility` 显示助手已绑定且 `Crashed services` 为空。
2. 游戏在前台、处于庭院（人工截图核对）；若不在庭院，人工把游戏回到庭院后再开始，或者询问用户。
3. 礼包已刷新：只读查看不需要；直接由任务判断。

## 步骤

1. 触发 `open-daily-gift`：卷轴 → 商店图标 → 若有下载框则“取消” → 礼包屋 → 日常灯笼 → 核对“每日礼包”。
2. 截图核对确实停在礼包屋日常列表。
3. 触发 `daily-gift`：
   - 判为可领取：点击一次“领取”，核对“获得奖励”，关闭奖励弹窗，关闭详情，核对回到列表；
   - 判为付费：不输入，直接完成。
4. 截图核对最终画面，并把详情页的“已领取”红章作为第三天样本（只在本地保存）。

## 停止规则

- 任何一步结果为未知、失败或被拒绝时，不重试、不改用手动点击补完，先截图，再报告用户。
- 出现付费、充值、兑换、退出确认或任何未见过的对话框时，立即停止。
- 全程不点击任何价格按钮；不按系统返回键（已知会弹出游戏退出确认）。
