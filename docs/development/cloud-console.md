# 云端控制台开发说明

设计见 [护肝宝云端控制方案](../design/cloud-executor.md)。本文说明当前已实现的范围和本地运行方法。

> 2026-11-19：设计已定稿为“游戏账号管内容、应用只执行、服务端调度”。第 1 期（设备连接）和第 2 期第①步（游戏账号、按账号的设置和计划）已完成。作业仍经长轮询领取，计划还不会自动触发，App 仍用本机的设置和计划，这些在第 2 期后续步骤里改，见设计文档第 10 节。

## 已实现

| 模块 | 内容 |
| --- | --- |
| 用户 | 邮箱密码、邮箱验证码、找回密码、GitHub 登录，登录限频，会话可吊销 |
| 设备 | App 登录后自动注册，经 WebSocket 上报状态、可用任务和应用（这台设备上装了的、护肝宝支持的游戏），控制台可解绑 |
| 连接 | App ↔ 服务端：`/api/device/socket`，状态变化时上报、无变化每 15 秒一次，双方 20 秒一次 ping；断线后 App 每 5 秒重连，令牌失效先续期。服务端只在连接打开时显示设备在线。网页：`/api/events`（SSE），先推快照，再推设备、作业、明细变化；断线重连带上次事件编号，能补发就补发，否则重推快照。网页不再定时整页刷新 |
| 作业 | 控制台下发、租约、取消、结果上报、失联处理；作业带任务版本和配置快照 |
| 游戏账号 | 网页按游戏添加、改名、删除账号（UID 可选）；只能为设备上报过的游戏建账号。设备上的每个应用可指定当前登录的账号和默认账号（自动识别前由用户手动指定） |
| 任务设置 | 以服务端为准，按“游戏账号 + 任务”保存，用执行引擎同一套规则校验；表单按这个用户最近上传、含该任务的任务包生成 |
| 计划 | 属于游戏账号，存服务端：运行周期、时间、任务、可运行设备（默认所有）、最晚开始时间（默认 30 分钟）、启用；保存按版本号防覆盖。计划时区按护肝宝账号设置，默认 Asia/Shanghai。**服务端还不会按计划触发运行**（第 2 期第②步） |
| 任务版本 | 设备状态里带当前任务包的版本和摘要，云端缺这一版时经 socket 通知设备上传一次；配置按设备实际运行的版本校验 |
| Web 控制台 | 登录注册、设备列表、任务设置、下发作业、作业记录 |
| App | 设置 → 云端控制，登录后自动领取作业，按作业带来的配置执行，不读本机保存的配置 |

作业状态规则：

- 设备领取后 30 秒内必须确认开始，否则作业回到队列。
- 已开始的作业失联后标记为“结果未知”，**绝不自动重试**，避免重复操作游戏。
- App 重启后用同一个命令编号恢复作业，不会重复启动。
- 下发作业时复制一份当时的云端配置，并按设备当前的任务版本校验；必填项没保存会直接拒绝下发。
- 设备领取后先核对任务版本摘要，和作业不一致就上报失败、不执行，避免同一份配置在另一个版本里含义不同。

## 尚未实现

- 游戏登录态的加密托管、下发和回传（要先在专用 Root 设备上验证）。
- 云端计划调度：计划目前仍在 App 本地，计划运行仍使用本机配置。
- 运行明细上报：作业只回报最终状态和一句话，还看不到停在哪一步。
- App 设置页登录后仍可修改本机配置，这些配置只影响本机手动运行和本地计划。
- 正式发信服务：未配置时，需要发邮件的接口返回“发信服务未配置”。
- 生产部署、HTTPS 证书、数据库备份。

## 本地运行

```bash
export JAVA_HOME=/opt/homebrew/opt/openjdk@17
./gradlew :core:server:installDist
YYS_SECRET="$(openssl rand -base64 48)" YYS_MAIL_MODE=console YYS_SECURE_COOKIES=false core/server/build/install/server/bin/server
```

打开 <http://127.0.0.1:8787>。`YYS_MAIL_MODE=console` 会把验证码打印到服务端控制台，只能用于本地开发。

模拟器里的调试版 App 用 `http://10.0.2.2:8787` 连接本机服务。正式版只接受 https 地址。

## 环境变量

| 变量 | 必填 | 说明 |
| --- | --- | --- |
| `YYS_SECRET` | 是 | 至少 32 位随机字符，用于验证码摘要 |
| `YYS_DB` | 否 | SQLite 文件路径，默认 `yys-cloud.db` |
| `YYS_HOST` / `YYS_PORT` | 否 | 监听地址，默认 `127.0.0.1:8787` |
| `YYS_PUBLIC_URL` | 否 | 对外地址，GitHub 回调要用 |
| `YYS_SECURE_COOKIES` | 否 | 只有本地 http 调试时才设为 `false` |
| `YYS_MAIL_MODE` | 否 | `console` 仅用于本地开发 |
| `GITHUB_CLIENT_ID` / `GITHUB_CLIENT_SECRET` | 否 | 不配置时 GitHub 登录不可用 |
