## 显示异常与当前验证入口

用户随后反馈模拟器画面看不清。ADB 实际帧复现了大块黑色缺图，不是仅凭桌面窗口判断。自动 GPU 模式的日志显示：因内存压力选择 Lavapipe／SwANGLE，出现 ColorBuffer 错误。显式 SwiftShader 后背景部分恢复，但按钮仍有黑块；游戏加载期间反复出现 `s_glCompressedTexImage2D` 的 `supportedCompressedFormat` 校验错误 `0x500`。硬件后端已确认切到 Apple GPU，仍未取得可用游戏画面，客户端观察到退回桌面；未取得足够退出原因，不能称已修复。

这是当前模拟器图形路径的兼容性障碍，不用助手业务代码补偿，也未修改游戏 APK／资源。Android 11 官方 ARM64 镜像已取得，作为后续兼容对照候选，尚未通过游戏验证。原 Android 16 AVD 数据保留。

用户提出连接真实 Android 手机，已提供 USB 调试授权步骤；初次 ADB 检查尚无已授权真机。接入后先识别型号、系统与 ABI，再按实际环境验证。此前的模拟器成功或失败不替代真机结果。
