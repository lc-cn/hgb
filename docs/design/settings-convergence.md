# App 交互与设置交付核对

适用范围说明：本记录与512项浏览器检查对应此前交付的原型源码。之后确认的“唯一任务执行器暂停，恢复动作分继续／重新开始当前任务”已进入PRD及架构重审，但尚未同步为原型新命令或按钮，不在本记录的已验证范围内。

日期：2026-11-15。基线：[PRD v2.4](../PRD.md)。入口：[可点击原型](../prototype/app-v2.html)。本稿覆盖工作台、任务／计划、模型、通知、历史、网络及游戏账号的本轮收敛；是产品交互与内存模拟，尚未实现 Android 应用。

## 信息布局

| 板块 | 本轮取舍 |
| --- | --- |
| 工作台 | 标题同行展示大区、昵称与游戏图标操作。未启动可下拉选择待启动账号并启动；启动后禁切换；运行账号尚未保存时显示保存图标，另有停止游戏。删除重复运行更多菜单。 |
| 执行与队列 | 任务／计划名作为主文本，运行状态与优先级作次文本。排队区带数量，保留右滑和行内移除。移除、暂停与停止的既定语义不变。 |
| 结果 | 删除用全部历史完成数冒充“今日与本周”的摘要，保留真实最近结果；工作台按已核对账号显示，下次计划也按账号。 |
| 任务配置 | 执行步骤默认收起，按需展开，让参数更早进入视线；常用、入队／暂停仍留列表行，不在详情重复放置。 |
| 计划编辑 | 已选任务行直接移除引用或调整顺序，候选仅展示未选任务。字段与已选安排在横屏分列。 |
| 设置与通知管理 | 横屏入口双列；高频游戏操作回到工作台，设置仅保留账号资料与开机自启。 |
| 历史记录 | 通知／运行两标签，去掉待处理；横屏标签在左、记录在右。 |

图标具有可访问名称，账号菜单支持再次点击、点击外部或 Escape 收起。长信息省略不挤占操作区。单选与多选仍使用既定按钮组，竖屏纵排、横屏横向换行；服务商下拉是已确认的例外。本轮没有新增业务触发、自动切号、重试或通知默认。

## 游戏与账号

游戏停止前不能选择其他账号，模块入口同样拒绝跨账号启动，不能绕过界面禁用。选择待启动账号只表示下一次启动目标，不把它冒充实际登录身份。启动后须新观察核对身份，失败时工作台按需显示提示及已有回退入口。

当前登录态保存策略先暂停队列并关闭游戏，因此点保存图标会先说明影响，再保存未验证快照；没有承诺运行中无影响保存。恢复后账号实际改变且核对成功，才清空旧未结束队列，失败／回退不清原队列。流程仍保持人工暂停，等待用户继续；unknown证据不因换号或删除消失。

计划保存时绑定所属账号，旧计划继续归旧账号，编辑不自动改绑。列表、下次计划、任务结果与摘要按当前已核对账号显示，全局历史标明账号来源。原计划到点锁原账号等待匹配，不在新账号执行，不自动切号或补做。删除本地快照不删除计划／历史。助手开机自启只保存偏好并在模拟开机后等待授权、身份核对，不自动启动游戏或恢复执行。

真实 Root 提取／恢复尚未进行：当前没有ADB或Android设备连接器。权限、设备与渠道版本、实际登录态依赖及失败回退须按[设备验证矩阵](game-lifecycle-account-boundaries.md)验证，内存模型不替代设备证据。

## 模型、通知、历史与网络

服务商用下拉选择，右侧配置按钮按需展开，另有新增具名服务商；普通路径按预设引导获取并填写密钥。切换不隐式保存或验证，草稿按服务分别保留，密钥按服务／地域／地址／协议绑定；公开快照不导出密钥。

通知管理包含渠道、事件规则与事件记录。渠道支持本机、钉钉、企微、Bark、邮件、自定义Webhook；添加、测试、保存均在对应顶栏右侧，测试草稿不隐式保存，记录保留测试时名称。凭据按渠道类型、目标与认证账号绑定，切换目标不复用旧凭据。

运行事实 → 独立规则 → 事件 → 已启用渠道订阅 → 投递记录。无订阅仍保留事件；通知不拥有队列或业务结果。首批11项规则包括任务开始／成功、计划开始／结束，以及失败、未知、排队、无进展、能力中断、资源／容量及视觉服务异常；全关起步，建议阈值只作编辑预填。事件不因后补订阅回放，生命周期恢复不重复报开始。详见[事件通知架构](event-notification-architecture.md)及[依据](../research/event-rule-rationale.md)。

网络设置支持 HTTP／SOCKS5、主机／端口、可选用户名密码，用户选择视觉模型、任务更新和外部通知哪些走代理；默认直连且范围为空。保存与显式配置检查分开，不创建系统VPN，不自动重试，也没有真实代理连接。单次模拟请求保留当时路由版本，避免设置修改篡改历史。

## 验证证据

[机器记录](verification-settings.json)绑定最终HTML、三个模块及其测试的源码指纹。浏览器共512项通过：页面与队列195、工作台与账号隔离39、游戏生命周期40、模型47、通知渠道71、事件历史55、网络47、布局与计划归属18。Node共72个情境通过：调度32、事件18、游戏账号22。

验证包括真实浏览器按钮／手势、横竖屏页面访问、选中与候选任务互转、菜单关闭与焦点、计划原账号锁定、启动后切号拒绝、失败回退保留队列、确认切号清队列、未知结果保护、事件和投递分离、凭据隔离及公开快照脱敏。游戏守卫新增回归曾在修改前真实失败。当前任务标题改为任务名后，既有移除检查改为验证次文本中的“移除中”，没有删除状态断言。

这些是一次内存会话与明确夹具下的本地证据，不证明持久化、真实定时、Root登录态恢复、实际截图输入、跨主题识别、自主新活动、外部请求或24小时稳定性。未构建APK，未发布或部署。较早[队列交付记录](execution-convergence.md)及其JSON保留原源码基线，不用于替代本轮验证。
