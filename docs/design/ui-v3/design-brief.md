# UI v3 共同设计基线

2026-11-15。交付是原生Android风格高保真设计稿／本地可点预览，不是生产App。保留旧原型与测试，不改docs/prototype/app-v2.html和三个模拟器。工程仍为现有HTML/CSS/JS，不增加框架或外部运行依赖。

视觉：温和的浅色工具App，暖白背景、深灰绿正文、一种克制的苔绿色强调色。不要网站hero、营销卡片、数据大屏、全屏网页侧栏、装饰照片、渐变或玻璃层。字体为Android风格系统无衬线，正文14–15、辅助12–13、标题20–22，禁用淡到难读的小字。使用一致的线性图标，控件有清晰按压与焦点。图标本体18–22，触达尽量44；悬浮控制不扩成巨大启动／暂停块。

共享token文件由根维护；main设计师另写base.css提供共享App壳、顶栏、列表、表单、按钮等组件。developer设计师引用同一base.css并仅补作者流程布局。新稿边缘为轻量Android设备框，竖412×860、横900×412。真实项目有responsive行为，评审尺寸只是导出画板。画面外有方向/页面选择与“本地设计模拟”说明，不向产品界面塞实现解释。

五导航：工作台、任务中心、托管计划、历史记录、设置。详情页返回，无重复五导航。工作台标题同行账号（大区+昵称）、未启动下拉+启动，运行后切换禁用，未保存账号保存图标和停止游戏。队列、任务名与控制优先，历史摘要次要，横屏左主右队列等不均分，避免页面整体长滚。

任务/计划列表行：星标常用，未入队图标加入队列，队列中标识且按钮禁用，当前为暂停；长按停止仍保持全队暂停。暂停属唯一Executor；恢复时提供继续（未完成步骤入口）/重新开始（当前任务第一步），其他任务不变。计划无独立暂停/恢复状态。状态、错误、空态可评审，别改业务默认。

版本页：一行只版本+更新时间，右启用/删除；已启用按钮禁用显示已启用，删除置灰，点行展开changelog，再点收起。任务中心右上当前启用版本，非已知最新版红点，点进更新。拉取最新版不自动启用。

表单：单选按钮组，多选按钮组；竖屏纵向、横屏横向换行。模型服务商下拉是例外，右侧配置+新增、配置按需展开。数值适当滑块或精确数字，时间日期原生选择器，不假造预算上限。计划只有每日/指定星期，无总开关；保存后按时间生效。计划选择任务已选行可排序移除，候选不重复已选。

通知管理分渠道/规则/事件；渠道支持本机、钉钉、企微、Bark、邮件、Webhook，添加右上，编辑测试/保存右上。11规则全关，事件不等于投递。历史仅通知/运行，横屏左tabs。代理按任务源/模型/外部通知范围，保存/测试不同。账号Root快照、启动授权及能力均模拟，不冒充真实功能。

开发者：GitHub授权登录+指定任务仓库权限，未授权不能打开制作/调试/发布；GitHub真实写权限最终决定Release发布。模拟无权限状态与网络未知状态分别展示。制作：新建/复制任务→选动作填参数→编排步骤→配置schema字段→调试→填写版本和说明→上传即发布Release。App提供动作；Task=步骤+schema，Plan=任务+时间。表单生成JSON，无必须手写代码、无巨大节点画布。调试看当前步骤动作、输入输出、识别画面和错误位置，复用唯一Executor。上传只模拟，无真实GitHub请求或令牌。一次上传完成发布，用户无第二个发布按钮或云草稿工作流。

三层悬浮：小球→快捷→常用。当前控制只显示一次，任务右侧小图标启动/暂停/停止，常用按场景内部过滤，不解释过滤算法，不暴露支持矩阵。

所有业务样例、时间、账号、版本、数值及调试结果均为模拟，不作为生产默认。设计师不得改PRD/架构或设置新自动化、隐式网络调用、实际发布。每份设计须提供截图页清单与自审，根统一导出截图和浏览器验证。
