# 开发者制作与调试 UI v3

日期：2026-11-15。交付为本地 HTML/CSS/JS 高保真交互稿，不是 Android 实现，也不证明真实 GitHub 权限、游戏识别或任务执行可用。

## 入口与设计

- 文件：`developer.html`，默认落在未登录的 GitHub 保护入口。主 App 设置直接链接此文件。
- 横屏：`developer.html?orientation=landscape`，设备框 900 × 412；竖屏 412 × 860。
- 使用共享 `tokens.css` → `base.css` → 本文件的 `developer.css`，仅追加 `dev-*` 作者布局；没有框架、外部字体、真实网络或脚本执行扩展。
- Android 单详情结构：返回／标题／就近动作。制作列表→任务→步骤→动作逐层进入，不用节点画布、多窗口 IDE 或手写 JSON。
- 横屏为不均分且各自滚动的两列：任务信息／步骤，步骤说明／动作，动作参数／输出，画面／调试结果，版本概览／更新说明。竖屏按内容顺序阅读。
- 数值可精确输入；schema 字段支持滑块与精确值，用户配置预览同步显示。日期、时间使用原生输入。单选和多选均为按钮组，竖屏纵向，横屏横向换行。

## 页面与路径

| 页面 | hash / 路径 | 主要交互 |
| --- | --- | --- |
| GitHub 授权 | `#auth` | 未登录、等待、有指定仓库写权限、无权限、网络未知、授权失效 |
| 制作列表 | `#tasks` | 新建、复制、打开任务、上传完整任务集 |
| 任务 | `#task/jade-claim` | 基本信息、步骤列表、新增／复制／排序／删除步骤、配置／资源／JSON／调试入口 |
| 步骤 | `#step/open-entry` | 名称、动作列表、新增／复制／排序／删除动作 |
| 动作目录 | `#actions` | 选择 App 提供的定位、点击、识别、核对、等待、滑动、获取画面 |
| 动作参数 | `#action/locate-entry` | 动作合同生成表单；固定值／任务配置／前序输出；输出命名；定位错误 |

`window.uiV3Developer.getManifest()` 返回当前页面索引。动态新建任务／步骤／动作使用生成 id，路径同表。

## 可点击演示路径

1. App 内「使用 GitHub 授权」只进入等待界面；画面外「有写权限」夹具才能注入成功身份。进入「永久勾玉卡产出」。
2. 点击步骤进入动作，编辑参数，使用固定值／任务配置／前序输出切换来源；输入区域常量时为四个数值字段，无需输入 JSON。
3. 返回任务，编辑配置字段；旋转后继续编辑。配置预览使用按钮、滑块、精确值、日期／时间等控件。
4. 画面外「切换资源缺失」，JSON 校验产生可定位问题，调试和上传被阻止；再切回可用继续。
5. 调试整个任务，点击暂停；继续会从当前未完成步骤入口开始，保留完成步骤。重新开始从当前任务第一个步骤开始。返回编辑草稿不会替换执行器快照。
6. 画面外调试结果选择「定位失败」或「结果未知」，再次试跑。结果未知时恢复按钮禁用，需人工核对并明确确认可重做后恢复；确认不代表真实识别已通过。
7. 上传页展示当前全部任务。点击顶栏「上传」即执行发布，无第二个发布动作。画面外可选成功／确定失败／响应未知／权限失效。成功显示版本与时间；确定失败可重新上传；结果未知仅可检查版本，不能盲目重发。
8. 上传中撤销授权，回调不能转为成功；远端结果未确认时保持结果未知，重新授权也不会解除重复上传阻断。GitHub 已明确拒绝发布的权限失效，重新授权后恢复原版本号和说明的可编辑／上传状态。发布成功返回制作后，再打开上传会建立下一版本表单。

## 本地评审 API

```js
const ui = window.uiV3Developer;
ui.getState();                 // 深拷贝，无凭据或可写内部对象
ui.getManifest();
ui.navigate('task/jade-claim'); // 受保护，无权限时回授权页
ui.setOrientation('landscape'); // 或 portrait
ui.reviewAuthState('authorized');
ui.reviewAuthState('denied');  // signedout / pending / unknown / expired
ui.reviewAuthState({state: 'authorized', repo: 'arbitrary/fork'}); // 被拒绝，不能解锁指定仓库
ui.reviewDebugState('paused'); // idle / running / success / failed / unknown
ui.reviewPublishState('unknown'); // idle / uploading / success / failed / expired
```

状态注入 API 与画面外按钮仅用于评审。App 内没有开发开关、强制权限通过、真实授权网址请求或真实上传。仓库名 `onmyoji-assist/tasks` 是展示占位夹具，不代表已经选择或绑定真实仓库。

## 状态归属与保护

- 路由、生成菜单的命令、输入修改和调试／发布异步完成均检查指定任务仓库授权。普通 GitHub 身份、自有仓库或 fork 写权限不能通过。网络未知与确定无权限分别显示。
- 结果未知时顶栏重置按钮禁用，命令入口同样拒绝重置，并保留未决输入／输出／日志。只有明确人工核对并确认当前步骤可重做才解除；不能用重置绕过。
- 调试只有一个 `executor` 投影；进入调试保持托管队列暂停，离开不自动恢复队列。没有第二个调试调度器或计划暂停状态。
- 试跑前校验实际测试配置的必填、数值范围／步长、选项、时间／日期和日期范围。非法值保留，跳转配置预览并定位字段。
- 开始试跑固定任务草稿和测试配置快照。继续使用该快照，重新执行当前未完成步骤；重做从同一当前任务的第一步骤开始。下一次独立试跑才取新草稿。
- 配置编辑草稿按任务／字段缓存，旋转、返回详情不清空；测试配置按任务隔离，不改普通用户配置或启用版本。
- 点击上传固定完整任务集、版本、说明快照，其他任务保留。在途编辑不改变这次上传。成功不自动替普通用户启用、排队或启动任务。
- 令牌没有被创建、模拟保存、输出到 JSON 或日志。所有数据仅内存保存，刷新重置。

## 自审与验证

已通过 `node --check developer.js`。用 Node VM 的最小 DOM/计时器夹具检查了真实事件命令入口和导出 API：全部受保护直接路由、未授权新建阻断、非指定 fork 拒绝、网络未知、字段旋转保存、动作引用与常量区域、在途草稿快照、暂停后继续／重做、未知结果禁止恢复、完整任务集上传快照、授权撤销后命令和上传回调阻断。

这只是本地命令／状态验证，不是浏览器渲染测试或真实游戏／GitHub验证。浏览器截图、可点击控件位置、横竖屏溢出和字体可读性由根 agent 统一验收。示例领取页以 CSS 图形表达定位反馈，不是游戏截图；示例任务不是经过验证的游戏流程。资源库是评审样本，真实截图截取／资源导入、实际权限持久化和唯一 Executor 集成留给正式实现。

复审修正验证：未知结果下重置命令被拒绝且日志／输入不变；测试数值越界与步长错误、反向日期范围保留输入并定位；确定未发布的权限失效重授权可重试，响应未知重授权仍阻断；诊断直接路由受保护。仍待根 agent 浏览器复核。

复审 P2：配置错误附 taskId，按所属任务／字段展示；重新校验只替换当前任务的错误，不清其他任务的错误或非法值，避免同名配置字段跨任务串报。
