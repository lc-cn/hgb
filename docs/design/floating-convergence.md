# 单一三层与简洁界面交付

> 历史验证：下述检查对应加入队列状态机前的源码。当前需求以 PRD v2.0 与执行调度设计为准，不能用这些通过数证明新调度行为。

日期：2026-11-15。当前产品依据：[PRD v1.5](../PRD.md)。[打开原型](../prototype/app-v2.html)。当前稿取代 A/B/C 三套备选；旧研究和截图保留为历史资料。

## 已落实的结构

1. 收起小球：轻量入口，点击展开。
2. 快捷面板：当前任务与右侧暂停／继续、停止小图标，常用入口、简短异常入口和返回助手。
3. 常用列表：点常用才展示任务／计划，行右启动；顶部复用同一当前运行行。返回回到快捷层，关闭收起到球。

当前运行不参与候选过滤，长列表独立滚动，顶部控制不会滚走。方向切换保留层级和运行；打开、返回、收起和隐藏不改变运行。当前交互、URL 和评审工具里已经移除 A/B/C 切换，旧 variant URL 不再恢复备选。

## 任务版本与入口

任务中心右上角直接显示当前启用版本；与已知最新版不同时附小红点，点击进入任务更新。启用最新版后红点消失；未启用显示“未启用”，未知最新版不伪造红点。入口有对应无障碍标签。

任务更新只列本地版本。每行左侧版本及更新时间，右侧“启用”“删除”；当前行显示禁用的“已启用”，删除置灰。点击行正文展开／收起更新说明，按钮不触发行展开。删除后移除该本地行。顶栏一个“拉取”入口保留手动获取能力，启动自动拉取和版本内部保护不变。

界面不再放状态表格、版本标签、独立更新说明按钮、占用原因段落或版本原理说明。必要的禁用原因通过无障碍标签／悬停标题和帮助表达。

## 一并清理的文案

- 常用开关只显示“常用”，常用入口不解释场景过滤逻辑。
- 计划开关与引用任务不附操作教学，删除重复任务大标题。
- 模型页保留费用和必要验证反馈，移除重复的服务与启用状态区。
- 当前运行记录只保留任务、状态和核对进度；技术运行身份与实现说明不放普通页。
- 环境、悬浮、提醒、数据等页面移除泛化的原理说明。实际业务目标、资源影响、单位约束、错误原因仍保留。
- 设置直接链接[使用帮助](user-help.md)，不增加只有一个链接的中转页。开发诊断和设备框外的研究说明继续独立。
