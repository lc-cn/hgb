# UI v6 排版（2026-11-18 用户确认）

UI v6 取代 UI v5 的导航和页面结构。配色、图标风格和玻璃控件沿用 UI v5。排版参考了 assttyys_autojs 的分组列表和设置页思路，没有使用其代码或素材。

## 导航

- 主入口只有三个：**任务、计划、设置**。竖屏用底部导航，横屏用侧边导航。选中项的文字变为该页颜色，图标填充同色；未选中项是灰色线框。
- 有任务在运行、排队、暂停或需要核对时，主页面常驻运行状态：竖屏是导航上方的状态条，横屏是右侧面板。
- 点运行状态进入“运行队列”。停止当前任务前必须确认。
- “运行记录”不占主入口，从任务页顶栏和设置进入。

## 页面

| 页面 | 结构 |
| --- | --- |
| 任务 | 按分类分组，可折叠；全部／常用筛选、搜索、视图选项（只看常用、同时只展开一组）；每行有星标和运行按钮，点任务名展开“配置”和“运行记录”。横屏左侧选分组，右侧看任务 |
| 任务配置 | 字段按任务包声明的 `section` 分组，数字用加减器，开关字段用 `SWITCH`；首次打开自动填入 `recommended` 并标“推荐”，可一键恢复，都要用户保存后才生效 |
| 计划 | 下一次运行、计划列表（启用开关、星期、任务顺序、上次结果）、新建和编辑；保存只登记日程，不额外运行一次；错过超过 15 分钟只记录，不补做 |
| 运行记录 | 全部／需关注／已完成筛选，按天分组，最新的在前 |
| 设置 | 权限与运行环境、悬浮球、外观、任务与账号、数据与诊断、关于。横屏左侧选分组，右侧看内容 |

## 悬浮球

- 空闲 3 秒收成屏幕边缘的细条，点一下或向内拖动唤醒成小球；可在设置里关闭自动吸边。需要处理时不收起。
- 小球显示应用 Logo，外环表示状态：蓝色是运行进度，琥珀色是暂停，红色是需要处理；角标是排队数。
- 点小球展开扇形菜单：暂停/继续、停止、常用、返回助手。3 秒不操作自动收起；停止要连点两次。
- 拖动松手后吸附到最近的左右边缘。

## 花费与消耗配置

体力、加成、花费上限、御魂强化和处置都放在对应任务的配置里（路线图 8.1 节）。推荐值由任务包提供，实现每个任务时结合实测确定。

## 预览与实现的差异

- 运行中的任务行保留暂停按钮，预览里只有状态标签。
- 悬浮球的快捷菜单没有任务名标签和运行记录按钮，以减少遮挡游戏画面。
- 预览里的“显示隐藏的分组”没有实现，因为目前没有隐藏分组的功能。
- 预览里的“运行与数据”（存储占用）没有实现。
