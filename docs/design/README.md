制作分工已确认：App提供并更新动作能力；开发者在App开发者模式内编排步骤／任务和配置schema、调试并生成JSON，明确上传即发布新版本；用户拉取后配置执行或自行组合计划。制作应简单，建议选动作填表和复制任务，具体见[任务制作设计](developer-task-authoring.md)。JSON字段、动作接口及编辑细节尚未冻结。

最新执行控制口径：任务定义步骤，计划组织任务与时间，唯一任务执行器负责队列和暂停。执行器恢复时选择“继续”或“重新开始当前任务”，不为任务／计划各建暂停状态机。该口径已同步到架构评审稿；UI v3 已增加恢复二选入口，但主稿仅以绑定当前任务的 UI 态表达，未修改旧执行器游标。开发者调试也是本地夹具。旧 v2 验证记录不覆盖这些新增能力。

原型的外部评审工具条用于切方向、模拟游戏画面与调度事件，不属于正式 App 页面。任务、模型、通知及游戏画面全部使用内存演示数据；刷新重置，不发起真实服务请求、不操作游戏、不持久保存密钥。示例商品、数量、计划时间、筛选规则、场景映射和设置值均不构成产品默认。

产品核心为“稳定 Android 容器＋云端任务包”。游戏任务目录、流程、识别资源与表单描述独立更新；容器提供执行能力及管理页面。原型里的固定数据代表已缓存目录，云端传输和任务包运行时还未实现。完整边界见[容器与云任务架构](task-container-architecture.md)。

## 交互准则

- 任务点开直接配置，列表右侧将一次任务加入队列；计划同样加入一轮。队列中显示标识并禁用，执行中改为暂停／继续；同一任务／计划未结束不重复入队。
- 常用星标放在原任务／计划列表行，悬浮引用同一配置；不设置收藏管理、快捷添加或排序流程。
- 普通悬浮只显示当前画面可开始的常用项；未知画面与确定无候选分开，过滤不关闭常用。
- 工作台任务名为主、状态及优先级为次，不保留重复运行更多菜单；移除虚假的日／周全历史计数，最近结果按当前账号展示。
- 任务步骤默认收起；计划已选行可移除引用与排序，候选只显示未选任务。设置／通知管理入口横屏两列。
- 当前运行独立保留暂停、继续和停止。任务和整轮计划统一排队，高优安全抢占后可恢复；人工暂停／停止暂停全队。常用区不重复当前控制。
- 异常给出具体原因与相关入口；未知兑换先核对结果，改配置和保存不宣称问题已解决。
- 模型服务商使用下拉，右侧配置按需展开，可新增具名服务商；内置服务通常只填密钥，保存与主动模拟测试分开。
- 设置只保留一个通知管理入口，内含渠道、事件规则、事件记录。支持本机、钉钉、企微、Bark、邮件、自定义Webhook，添加、测试和保存均在顶栏右侧。
- 首批11项事件规则全关；规则、事实事件、已启用渠道订阅与投递独立。无订阅的事件也留记录，测试渠道不产生业务事件或隐式保存；提醒不自动取消、重试或恢复。建议阈值只在编辑预填，不冒充上游默认。
- 历史记录仅通知／运行两标签，横屏左标签右内容；工作台和异常详情保留处理入口。
- 网络设置支持HTTP／SOCKS5、可选认证及视觉模型／任务更新／外部通知范围，默认直连且范围为空；按已保存范围路由，保存不测试、不发网、不自动重试，不创建系统VPN。
- 游戏状态紧凑放工作台标题同行：大区／昵称，未启动时下拉选账号与图标启动，启动后禁切换；运行且未保存的账号显示保存图标，另有停止游戏图标。失败／待核对提示按需出现在内容顶部。
- 设置仅保留账号资料管理与开机自启，账号管理不重复游戏启动／采集或账号选择。采集只从工作台未保存账号图标进入，点击先短确认说明关闭影响，再复用暂停托管、停止游戏后的流程，非运行中无影响保存；Root真实一致性与恢复尚待设备验证。
- 成功核对账号实际改变后清空旧未结束队列，历史和unknown保留；失败／回退不清原队列，成功也保持hold等待用户继续。run只绑定opaque账号key和名称。
- 计划绑定所属账号，编辑不自动改绑；计划列表／下次计划与任务结果摘要按当前账号。旧计划到点锁原账号等待匹配，不自动切号或补做；删除本地快照保留计划和历史，全局历史标账号来源。
- 助手开机自启默认关闭；开机后待授权与身份核对，不自动解锁、拉起游戏或恢复队列。外部Root／账号／boot工具仅是内存评审夹具。
- 普通页面不展示技术支持矩阵。开发者模式受GitHub身份与指定仓库权限保护，包含任务制作、App内调试、上传Release及诊断，不增加游戏执行权限或自动上传；旧原型的开放开关尚未对齐保护方案。
