# 任务版本与悬浮控制增量验证

> 本记录对应版本管理增量时的历史源码。随后已将 A/B/C 收敛为一套三层悬浮；当前入口和验证见[三层收敛记录](floating-convergence.md)。

日期：2026-11-15。基线：[PRD v1.2](../PRD.md)。对象：[App v2 原型](../prototype/app-v2.html)。本轮仍是设计与内存演示，未实现真实远端分发、磁盘删除或 Android 服务。

## 本轮变化

- 一次 App 启动自动拉取最新版，手动可拉最新版或指定版本；导航和旋转不重触发，不覆盖用户所选版本。
- 同页展示逐版本发布日期、更新说明、本地状态和使用／删除操作。说明行内展开，顶部只保留“拉取最新版”。
- 使用历史版本后，新运行绑定该版本；当前运行仍锁旧版本，暂停仍占运行，切版不自动停止任务。
- 删除本地历史保留配置、常用、计划、远端版本和结果。当前、在途下载／运行和未决核对依赖显示占用原因；完成历史不永久锁住包。
- 展开悬浮面板中，当前任务右侧使用与启动相同的 34px 暂停／继续和停止小图标，不使用大暂停按钮。A 的图标条仍保留单一控制组，B/C 当前行不受候选过滤影响。

版本专项覆盖启动一次、导航／旋转不重拉、手动拉取、行内 changelog、指定新旧版本、删除与重新获取、当前／运行／未决依赖、在途去重与取消、失败释放引用、离线有缓存／无缓存、不兼容、配置与未知结果保留。B/C 两方向验证了按钮与启动同尺寸、位于任务右侧，未知场景仍能控制同一运行。

## 两项浏览器复现与修复

1. **下载与删除竞态。** 修复前拉取历史版本期间可删除，同版下载回调随后将 local 改回 true，刚删版本又出现。修复后在任务包获取所有者记录 operationVersion，删除校验只保护该下载目标，不封锁无关历史版本；完成、失败和取消释放引用。浏览器重验同版被拒绝、无关版可删、结束后删除不复活。
2. **自动拉取打断编辑焦点。** 修复前启动拉取完成会全页 render，模型 Key 草稿仍在但焦点丢失。修复后版本状态只刷新任务中心、任务更新和设置的相关视图。浏览器重验模型、任务、计划、渠道四类表单节点、焦点与草稿在完成回调后均保留。

另有架构子 agent 只读源码与独立 VM 复核，不操作上述 Chrome。验证不表示真实包下载、签名／digest 核验、schema 迁移、重启持久化或共享文件回收已经实现。
