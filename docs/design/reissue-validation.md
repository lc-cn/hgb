> 本记录对应初次重出稿的历史基线。后续版本管理及悬浮行内控制已调整，当前验证见[最新增量记录](version-management-validation.md)；旧检查数量与 SHA 不自动适用于新文件。

日期：2026-11-15<br>
对象：[App v2](../prototype/app-v2.html)，产品基线为 [PRD v1.1](../PRD.md)。验证的是可评审产品原型，不是 Android 应用或真实自动化能力。

## 结论与方法

完整原型覆盖五个主入口、六类业务及 22 项缓存云任务示例。最终清单为 49 个页面入口，包括任务更新和独立输入控件评审页；主 App 横竖屏、悬浮三种方案和关键状态均已实际渲染。

在独立临时 Chrome 环境打开本地文件，通过真实 DOM 操作和鼠标输入检查。每轮使用新的本地页面 URL，避免 hash 导航复用旧源码；不访问个人浏览器资料，不连接游戏或真实服务。Node 语法检查通过。

| 检查组 | 结果 |
| --- | --- |
| 49 页面 × 横竖屏 | 98 个布局组合通过，正文无横向溢出，操作区在设备框内 |
| 页面与核心交互 | 146 项通过，覆盖六类目录、原配置、行内执行、计划引用、暂停／停止及草稿 |
| 悬浮／模型／云任务专项 | 54 项通过，覆盖 A/B/C 两方向去重、未知场景保留控制、真实鼠标拖动、凭据归属、缓存和锁版 |
| 输入控件专项 | 16 项通过，覆盖真实滑块拖动与精确数值联动、保存校验、时间日期及旋转保留 |
| 总计 | 216 项检查通过；最终运行无脚本异常 |

[逐项结果与原型 SHA-256](../prototype/verification-v2.json)记录被检查的具体文件和结果。源文件后续变化需要重新判断受影响检查，不能沿用该文件的完成结论。各子 agent 的源码和惰性 DOM 内存复核另见[覆盖矩阵](reissue-requirements.md)及[架构复核](reissue-architecture-review.md)，不与浏览器测试冒充同一证据。

## 关键行为证据

- 任务正文直接进入含规则、资源与常用的配置页，右侧按钮执行一次。当前运行行直接暂停／继续；详情无仅用于返回的固定底栏。
- 任务与计划的 common 属性同源；执行计划一轮不会启用周期计划。修改规则更新原配置版本，运行使用开始时已保存的版本。
- 暂停先展示处理中再确认，暂停后另一个任务仍被当前运行阻止，不排队、不替换。停止确认后不自动开始其他任务。
- 切换庭院、商店、未知夹具会重新过滤常用候选，common 不变。计划按整轮示例条件判断；未知时当前运行的暂停／继续／停止保留。A/B/C 当前运行控制均去重。
- 密钥帮助链接官方入口；普通预设只填 Key。保存不触发能力测试，显式测试只模拟。切换草稿不丢原保存连接；更换服务或自定义地址不能借用不属于该连接的旧 Key。公开状态无测试密钥或自定义地址。
- 模型、任务和渠道问题进入对应配置。保存不清除问题、不自动执行；未知兑换优先核对，仍阻止重做。渠道测试不清除未知结果，通知接收不等于用户已读。
- 本机通知不展示外部地址／认证，切换类型时字段随之变化。开发诊断必须单独开启，查看不创建运行。
- 云任务检查和下载分别显示过程；下载只暂存。浏览器确认当前运行绑定旧包且启用返回忙碌；暂停时相同契约另由架构 agent 内存复核。结束运行不自动启用，主动启用后下次运行才绑定新版本。常用、配置、计划与未知问题保留。
- 网络失败且有缓存时，本地示例任务仍判定为可开始；首次无缓存展示空态且判定不可开始。不兼容的新包不能下载启用，旧缓存保留。线上恢复后可主动获取并启用。
- 有界滑块实际鼠标拖动时联动数字和草稿，不重建控件或丢失焦点；精确输入反向联动。次数 `2.5` 和低于最小值均拒绝保存；非法精确值保留并说明，未静默取整。无上界的数量不编造 max。
- 计划时刻为 time 控件，日期和日期范围端点为 date 控件；方向切换保留草稿。日期示例不写入计划，也不新增日期调度。

## 自审修复

发现并修复了无任务历史却跳到勾玉卡记录、A 浮层重复当前控制、自定义地址复用旧 Key、未保存切服务影响原保存 Key、数值字段声明 step 却允许保存小数等问题；修复后已针对性复核，并在最终版本进行回归。次数 2.5 在浏览器中观察到修复前可保存、修复后被拒绝；A 控制与模型归属的前后比较由架构 agent 在内存逻辑中完成。历史错关联由源码和模板追踪定位，未把它记为修复前后的真实点击对比。

## 未实现与未验证

目录、包版本和网络反馈是固定内存夹具。本轮没有实现或调用真实云目录、下载协议、签名／摘要核验、动态工作流解释器、持久离线包与升级迁移，不能据模拟版本变化宣称真实云任务分发已完成。

浏览器原生 date/time 控件表达交互意图；Android 最终控件、软键盘、无障碍、系统方向切换及进程恢复仍需真机验证。模拟截图和输入能力不证明系统权限、悬浮遮挡、触控或 Windows 模拟器兼容。

24 小时常驻、跨主题识别、陌生活动理解、真实模型与通知、消耗与结果核对均未验证。悬浮最终形态、任务来源和信任、后台拉取／自动启用、资源规则、提醒与留存策略及分期仍需后续评审；原型演示值不成为产品默认。
