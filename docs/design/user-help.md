# 使用帮助

当前可点击原型使用演示数据，没有连接设备、读取登录态，也没有连接游戏、模型、代理或真实通知服务，刷新后重置。

## 常用、任务与计划

在任务或计划列表点亮星标，可从悬浮常用列表快速操作；列表随当前游戏画面变化。没有入队时，运行按钮加入本次任务或一轮计划；队列中的按钮不可重复提交，当前执行项可暂停／继续。

任务配置具体目标、步骤、资源和保护条件；步骤说明默认收起，需要时展开。计划编辑中已选行可移除或排序，候选区只显示未选任务；移除不删除原任务。计划选择“每日”或“指定星期”及时间，有效保存后日程生效；周一单选就是每周一。保存计划不立即执行一轮。本轮完成后结束，也可选择限定最长时长，用小时、分钟填写。

工作台突出显示正在执行的任务名，状态与优先级显示在次要位置；可查看排队、自动挂起项及当前账号最近结果。更高优先级可在安全位置先执行，之后核对并恢复进度；计划使用全部成员优先级之和。手动暂停或长按停止都会暂停整个队列，继续前会重新观察并按优先级选择。停止还会结束本轮当前项。

暂停的是任务执行器。恢复时选“继续”，就跳过已完成步骤，从未完成步骤的入口执行；选“重新开始”，就让当前任务从第一步执行，其他任务不变。计划只是任务集合与定时提交规则，没有单独的暂停或重启。之前的结果与实际消耗保留，兑换等结果不明时先核对。该规则已确认，目前原型尚未增加重新开始入口。

右滑移除某项；移除当前项时需先结束其在途操作，再继续剩余队列，不等同于暂停全队。原有手动暂停不会被移除操作解除。未知结果仍需核对。

## 任务版本

启动会拉取最新版，任务版本页顶栏也可手动拉取。下载不改变所选版本，在对应行点“启用”；当前行为“已启用”。任务中心版本号旁的小红点表示与已知最新版不同。

点版本行展开／收起更新说明，可选择保留的旧版回退。删除只清理本地版本，任务设置、常用、计划和记录仍保留。当前、正在拉取、执行队列或未核对结果依赖的版本不能删除；未结束执行仍锁定原版本。

## 模型服务商和密钥

用下拉选择服务商，点右侧“配置”才展开字段；通过官方获取链接创建密钥。点“新增”可建立具名兼容服务，填写名称、协议、地址和模型后保存。

各服务商有独立草稿和凭据，切换不隐式保存或测试。密钥需要匹配服务、地域和目标地址；改变目标后不要混用旧密钥。保存与验证分开，真实能力验证可能消耗额度；当前原型只模拟。关闭模型后，本地已具备能力的任务仍可使用。

## 通知管理

设置中进入“通知管理”，再选择通知渠道、事件规则或事件记录。它取代旧的单独“排队等待通知”设置。

渠道支持本机、钉钉、企业微信、Bark、邮件及自定义Webhook。列表右上添加，编辑页右上测试／保存；按类型填写目标与必要认证。本机通知需要设备权限。测试使用当前草稿，不自动保存，也不会生成任务业务事件。

在事件规则中选择何时提醒，在渠道中选择订阅哪些事件并启用渠道。规则触发后即使没有订阅渠道，也可在事件记录查看；渠道投递结果在历史记录的“通知”标签查看。发送成功不表示问题已处理。

首批规则包括任务开始／成功、计划开始／结束、连续执行失败、结果待核对、排队等待过久、执行无进展、运行条件中断、资源或容量受限、视觉服务异常。全部初始关闭，需保存启用；次数／时长编辑框中的建议值可修改，不是已开启策略。计划结束可筛选结果。

恢复任务不重复发送开始提醒，开启规则不会补发旧开始、成功或结束事件。提醒不会自动取消、重试、恢复任务或购买资源；关闭提醒也不解除未知结果的核对要求。

## 历史与异常

历史记录只有“通知”“运行”两个标签，横屏在左侧切换。通知管理内的“事件记录”查看触发事实及其投递，两者不等同。

需要处理的问题从工作台或异常详情进入相关配置。兑换或强化结果未知时，先核对物品、限购次数、余额与证据；保存配置、通知已投递或更换任务版本都不能确认此前是否生效。

## 网络设置

默认直接连接。需要代理时选择“使用代理”，填写HTTP或SOCKS5、地址与端口，按需选择用户名密码认证。端口需为1–65535整数。

自行多选哪些服务走代理：云端视觉模型、任务更新、外部通知。未勾选范围不使用该代理；使用代理需明确配置范围，保存后才改变路由。更换目标需要对应凭据，不能串用。

保存不会测试、重试或发起网络请求，原型里的测试只是本地模拟检查。本设置不创建系统VPN，也不代理游戏或其他App。真实代理连接能力仍待实现与验证。

## 工作台游戏与账号

工作台标题旁显示账号大区与昵称。游戏未启动时，点账号资料下拉选择本次启动账号，再点旁边启动图标；启动后不能在此切换账号。停止游戏使用标题栏的停止游戏图标，与暂停／停止队列不同。

运行时当前账号尚未保存，会显示保存登录态图标。点保存图标会先简短确认：当前原型需要暂停托管并停止游戏后保存；确认后才继续，不能理解为运行中无影响保存；真实策略仍需设备验证。失败或身份待核对时，在工作台内容顶部查看原因与处理入口。

设置中的账号资料管理可查看、改名或删除本地快照，不重复提供游戏启动、采集与账号选择；采集从工作台未保存账号的图标进入。删除快照不会删除游戏账号；操作依赖中的快照暂时不能删。提取／强停／恢复需要受控Root能力，返回桌面不等于强停。

快照保存后仍是“未验证”。恢复后先核对UID、区服和渠道；不匹配时保持暂停，可恢复切换前状态后再次核对。设备、渠道或游戏版本不兼容时不能直接恢复。遇到尚未核对的消费结果，先核对旧账号，不要通过换号消除记录。

仅成功核对新账号且身份实际改变后，旧未结束队列才会清空，任务由新账号重新添加。历史及未知结果保留；恢复失败或回退不清原队列。切换成功也不会自动继续托管。

计划属于创建／保存时的账号，编辑旧计划不会改绑。计划列表和下次计划只显示当前账号；旧账号计划仍保留，新账号需重新创建自己的计划。旧计划到点会等待原账号匹配，不会用新账号执行，也不会自动切号或补做。删除登录态快照不会删除计划或历史。

任务最近结果与完成摘要按当前账号显示；历史记录保留全部账号，并标明来源。A账号的完成不会显示为B账号已完成。

当前原型账号A、Root能力和身份确认均为演示，没有实际提取或恢复，不代表可免登录或跨设备使用。专用Root环境的验证路线已接受，真实能力尚待验证，详见[游戏与账号能力边界](game-lifecycle-account-boundaries.md)。

## 助手开机自启

开机自启开关默认关闭。开启只表示希望开机恢复助手，之后仍需检查授权和账号；不会自动解锁、启动游戏、切账号或恢复执行队列。设备框外的boot按钮只是评审模拟，不是实际开机测试。
