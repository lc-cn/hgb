# 四项交互优化与原型交接

日期：2026-11-15<br>
状态：历史交互草案记录。最新稿为 [App v2](../prototype/app-v2.html)，以[完整蓝图](../PRD.md)及[本轮交付索引](README.md)为准。下文仅作演进对照，不代表真实 Android 或游戏能力已实现。

主交付：[原生交互方向草案](native-ui-preview.html)。本次在原生方向上增加功能路径，不恢复已被否定的旧网页式视觉稿；五个主入口、六类业务与三种悬浮变体保持。

## 一 任务与计划立即执行

任务和计划的列表行右侧直接放执行按钮，点任务执行一次，点计划执行一轮。不单独建设执行目录，不新增额外操作流程；当前忙碌时仍说明冲突，不静默替换或排队，待机／停止后可直接执行。

执行引用原规则与预算，不改变周期计划的启用状态。

## 二 模型预设与密钥引导

设置增加 Google Gemini、通义千问和高级自定义。两个预设的普通配置只需选择服务并粘贴 API Key；地址和模型标识放入高级设置。

| 预设 | 模型与服务范围 | 普通用户入口 |
| --- | --- | --- |
| Google Gemini | AI Studio／Developer API；Gemini 4 Hydrogen，`gemini-4-hydrogen` | API Key，内含三步引导与官方密钥管理页 |
| 通义千问 | 百炼中国站北京；通义千问 Plus，`qwen3.7-plus` | API Key，明确地域与按量付费类型要求 |
| 高级自定义 | 自行指定兼容服务地址和模型 | 密钥及高级参数，不冒充所有服务通用 |

参数与前提依据[模型预设技术核验](model-presets.md)。预设高级参数只读，自定义服务单独填写，避免普通用户误改地址。预设不会自动切换服务、地域或模型。

密钥输入为密码字段，仅存在本次页面的私有内存草稿，不写入持久存储、URL、通知或公开的原型检查 API；保存与验证均为模拟，不向任何服务发送请求。切换服务清空密钥草稿，避免把另一家的密钥当作当前服务配置。

引导解释百炼完整密钥只在创建时展示，不绘制“随时复制旧密钥”。真实能力验证需要发送请求且可能消耗额度；本原型按钮会明确报告模拟，不假装完成实际鉴权、视觉或游戏验证。

## 三 一个常用开关

任务和计划各有一个“常用”开关，开启后自动显示在悬浮球，关闭后移除。该值保存在任务／计划本身，不另外维护收藏集合，不提供快捷管理页、添加页或排序流程。

悬浮球直接列出常用项，右侧执行一次；当前关联运行则显示暂停／继续。修改常用不会启用周期计划，不会复制规则，也不会暂停无关运行。

## 四 异常以原因与配置为中心

| 具体原因 | 明确入口 | 修改后的语义 |
| --- | --- | --- |
| 模型密钥认证失败 | 修改模型密钥 | 保存配置不自动恢复游戏任务，需要重新验证与明确执行 |
| 御魂副本资源不足 | 修改目标次数／体力或门票预算 | 不自动购买资源、不增加余额，保存不等于资源条件已满足 |
| 商店兑换结果未知 | 查看核对要点、前往相关任务设置 | 配置不能确认之前是否已消费；保留未知结果，不自动重做 |

消息列表的正文可查看具体原因，右侧“改密钥／改目标”直接进入相关配置；未知兑换只提供“查看原因”，不伪装成配置即可修复。具体问题页和游戏内异常入口也使用对应事件类型与文案，不再统一写“查看并处理”。模型错误不会被显示为兑换未知的修复方法。

任务规则从问题页打开时，保存后回到同一问题；模型配置保存后保留在配置页，供继续验证。两者均不因保存成功清除异常。任务规则修改更新原型的配置版本，但不产生游戏动作。兑换未知的相关任务设置只影响未来规则，不能替代当前结果核对。

## 五 交互与截图入口

- 四项竖屏对照：`native-ui-preview.html?board=interaction`，采用两列两行，第四屏展示消息列表的具体配置入口。
- 四项横屏对照：`native-ui-preview.html?board=interaction&orientation=landscape`，纵向排列横屏设备。
- 任务列表：`?view=app#daily`；计划列表：`?view=app#plans`。
- 任务详情：`#task-detail`；计划详情：`#plan-detail`。
- 在任务详情 `#task-detail` 或计划详情 `#plan-detail` 切换“常用”。
- 模型：`#model`；异常：`?view=app&issue=auth#issue`，也支持 `resource` 和 `unknown`。
- 游戏控制：`?view=overlay&orientation=landscape&variant=a`，A／B／C 均可比较。

## 六 本轮检查重点

1. 待机时分别执行任务与计划，确认当前对象改变而计划启用状态不变。
2. 忙时尝试另一项，确认没有替换或排队；停止后可以重新点执行。
3. 常用开关与悬浮列表同步；仅当前关联项暂停或继续。
4. Gemini／通义千问预设只需密钥，高级参数及获取引导可打开；密钥字段不暴露到检查 API。
5. 三种错误进入正确配置或结果核对说明；保存不会自动重做游戏操作。
6. 横竖屏下长内容仍可滚动，详情固定操作不被遮挡；原有三种悬浮与主导航继续可用。

代码通过脚本语法检查。实际截图与浏览器交互由主 agent 继续核查，最终反馈应区分原型表现与真实 Android、模型或游戏验证。
