护肝宝是一个开源项目，代码公开在 GitHub。这份政策说明本站（网页控制台、安卓 App、Windows 客户端连接的这台服务器）怎样处理你的信息。如果你用的是别人自己部署的护肝宝，由那位运营者负责，以他的政策为准。

## 我们收集什么

只收集让护肝宝运转所必需的信息：

| 信息 | 从哪来 | 用来做什么 |
| --- | --- | --- |
| 邮箱地址、密码 | 你注册或绑定邮箱时填写 | 登录、找回密码、发送验证码和你订阅的通知。密码只保存经过 Argon2id 处理后的结果，任何人都看不到原文 |
| GitHub 账号编号和用户名 | 你用 GitHub 登录或绑定时由 GitHub 提供 | 登录。我们不读取你的仓库，也不保存 GitHub 的访问令牌 |
| 设备信息：设备名称、系统类型、App 生成的安装编号、在线状态、最后在线时间、装了哪些游戏 | 你登录的 App 上报 | 在控制台里显示设备，把任务派给正确的设备 |
| 游戏账号：你起的名字、游戏内编号和昵称 | 你填写，或 App 在游戏界面上读到后上报 | 区分多个游戏账号，让任务跑在正确的账号上 |
| 任务设置、计划、作业记录（每一步做了什么、结果如何）、通知记录 | 你在控制台设置，App 运行时上报 | 定时执行任务，显示运行结果，提醒你出了什么事 |
| 通知渠道配置（如钉钉、企业微信机器人地址和密钥） | 你填写 | 把通知发到你指定的地方。密钥加密保存 |
| 计划时区 | 你选择 | 按你的时间执行计划 |
| 访问日志：IP 地址、时间、请求的地址 | 访问服务器时自动产生 | 排查故障、防止滥用 |

**不收集**：游戏的登录密码（你在游戏里自己输入，护肝宝不读取也不保存）、手机上的截图和画面（识别都在你的手机上完成，画面不会上传）、通讯录、位置、短信等与任务无关的信息。网站和控制台不使用统计分析或广告追踪。

## 存在哪里，交给了谁

我们不出售、不出租你的信息，也不把它用于广告。下面这些服务商在提供服务时会接触到部分信息：

| 服务商 | 做什么 | 接触到什么 |
| --- | --- | --- |
| Oracle Cloud（新加坡） | 运行服务器、存放数据库 | 上面列出的全部账号数据 |
| Cloudflare | 域名解析、HTTPS、防攻击，所有请求都经过它 | IP 地址和请求内容 |
| Vercel | 托管网站和网页控制台的页面文件 | 访问网页时的 IP 地址 |
| 阿里云邮件推送 | 发送验证码和邮件通知 | 你的邮箱地址和邮件内容 |
| GitHub | 用 GitHub 登录；托管 App 安装包和任务包的下载 | 你在 GitHub 上的登录行为；下载时的 IP 地址 |
| 你自己配置的通知渠道（钉钉、企业微信、Bark、Webhook 等） | 接收你订阅的通知 | 通知的标题和内容 |

服务器位于新加坡，你的数据会被传输到中国大陆以外存储和处理。使用护肝宝即表示你知悉这一点。

## 保留多久

- 账号数据：保留到你注销账号为止。注销后立即从数据库删除。
- 数据库备份：每次更新服务器前会做一次备份，每天检查一次，超过 14 天的自动删除。所以注销后，你的数据最多还会在备份里留存 14 天，期间不会被使用，到期即删除。
- 验证码：10 分钟后失效。
- 访问日志：保留 14 天。

## 你的权利

- **查看和修改**：登录控制台即可查看设备、游戏账号、计划、作业记录和通知，并随时修改或删除。
- **绑定和解绑登录方式**：在“我的 → 登录方式”里绑定邮箱或 GitHub，至少保留一种。
- **合并账号**：如果你用邮箱和 GitHub 各注册过一个账号，绑定时证明两个都是你的，即可合并成一个。合并后另一个账号被删除，在浏览器里登录着它的会退出。
- **注销账号**：在“我的”页面底部注销。账号有邮箱时需要输入邮箱验证码。注销会删除账号和其中的全部数据，不能恢复。
- **导出或其他请求**：在 <a href={`${repoUrl}/issues`}>GitHub Issues</a> 提出（请勿在公开 Issue 里写邮箱等个人信息，我们会另行联系你）。

## 未成年人

护肝宝面向能够自行管理游戏账号的用户。未满 14 周岁的未成年人请在监护人同意和陪同下使用。

## 安全

数据传输全程使用 HTTPS；密码只保存不可逆的处理结果；通知渠道的密钥加密保存；网页登录状态保存在浏览器无法被脚本读取的 Cookie 里。没有任何系统能保证绝对安全，如果发生影响你的安全事件，我们会通过你的邮箱或站内通知告诉你。

## 政策更新

政策有变化时，我们会更新这一页并修改顶部的生效日期；重大变化会在控制台里提示。更新后继续使用即表示你接受新的政策。
