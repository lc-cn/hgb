title: 游戏账号和切号

---

游戏账号是护肝宝里最重要的概念：任务设置、计划和运行记录都跟着游戏账号走，不管它在哪台设备上跑。

## 添加

- **手动添加**：控制台 → 游戏账号 → 添加，填名称、编号和游戏昵称。
- **从设备上识别**（游戏支持识别账号时）：在游戏里登录这个号，在 App 的“云端控制”页点“识别”，再点“保存”，以游戏昵称为名保存；在控制台的设备卡片上可以起名保存。

编号就是游戏里的 UID，同一个游戏里不能重复。

## 自动切号

游戏的任务包提供了“识别当前账号”和“切换账号”两个任务时才能自动切号。阴阳师的这两个任务还在调试，还没随任务版本发布。

一个任务要在某个账号上跑时：

1. 设备先识别游戏里当前登录的账号；
2. 编号一致就直接跑；
3. 不一致就按**游戏昵称**在游戏的“已有角色”里选到那个号，进入游戏后再识别一次；
4. 编号对上才开始；对不上，这次不跑，作业记为失败并写明原因。

应用设了默认账号的，跑完会切回去；切不回去会记在结果里，打开“账号没切回”规则还会通知你。

:::caution
切号只从游戏自己记住的账号里选，护肝宝不会也不能帮你登录一个游戏没记住的号。遇到验证码或没见过的页面会停下等你。
:::

## 同一个账号不会两处同时跑

一个账号同一时间只在一个应用上跑，跨设备也一样。另一处正在跑时，新的作业会排在后面。
