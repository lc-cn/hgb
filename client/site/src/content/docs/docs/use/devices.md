控制台的“设备”页列出你所有登录了护肝宝的设备：在不在线、现在在跑什么、最近一次运行的结果。点进一台设备，可以看到它上面的应用（游戏）。

## 应用详情

- **运行**：当前正在跑的任务、进度，可以暂停或停止；后面排队的任务；在这个应用上立即运行某个任务。
- **运行记录**：这个应用上跑过的所有任务，不分账号。

## 当前账号和默认账号

- **当前登录**：游戏里现在登录的是哪个账号。游戏支持识别账号的，由设备自己读出来；不支持的，在这里手动选。
- **默认账号**：这个应用平时应该登录哪个号。设了之后：
  - 计划不会让这个应用切去跑别的账号；
  - 你在网页上让它切号跑别的账号，跑完会自动切回默认账号。

## 解绑设备

在“我的 · 我的设备”里可以解绑。解绑后这台设备下线，正在运行的作业结果会标为未知。
