每次运行一个任务就是一个**作业**。在设备、应用、游戏账号的“运行记录”里点一行，能看到它的每一步。

## 状态

| 状态 | 意思 |
| --- | --- |
| 等可用应用 | 还没有应用能接，服务端在等 |
| 排队中 | 交给了某个应用，排在它前面的跑完再开始 |
| 已下发 | 已经发给设备，等设备开始 |
| 运行中 | 设备正在跑；暂停后显示“暂停中”，停止时显示“取消中” |
| 已完成 | 跑完了 |
| 失败 | 跑不下去了，原因写在旁边 |
| 结果未知 | 操作可能生效了，但没法确认，比如点了之后画面没认出来。需要你看一眼游戏 |
| 已取消 | 你停止或取消了它 |
| 已跳过 | 过了最晚开始时间还没轮到 |

## 步骤明细

每一步一行：打勾的是完成了，感叹号是停在这里。点开能看到这一步做了哪些动作、各用了多久。作业前后有识别账号或切号时，这些步骤也会列在里面。

## 结果待核对

“结果未知”的作业会在手机的悬浮球上提示你核对：看一眼游戏，告诉护肝宝那一步到底有没有生效。核对之前，这台设备不会接着跑别的任务。
