sidebar: { order: 2 }
---

“开发”入口只对开发者显示：护肝宝账号绑定了 GitHub，而且是任务仓库有写权限的协作者。

1. **做步骤**：在 App 里截取当前游戏画面，框选区域，选“等画面、找图、找字、点击”。“试一下”只识别，不会点击游戏。
2. **拼任务**：从步骤库引用步骤，设条件和分支，定义设置项。
3. **调试**：在本机直接运行草稿。悬浮面板显示当前步骤、识别区域和最接近的候选，可以重试、单步，或者用当前画面回去改步骤。
