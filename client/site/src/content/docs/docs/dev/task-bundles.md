---
title: 任务包是什么
description: 任务包里有什么：目标、步骤、任务、设置项，以及版本。
sidebar: { order: 1 }
---

护肝宝本身只会“看画面、找图、找字、点击”这些基础动作；具体做什么，写在**任务包**里。任务包是一份 JSON，加上它用到的图片，按游戏组织：

- **目标**：一个游戏，写明它在安卓上的包名，以及可选的“识别当前账号”“切换账号”两个任务。
- **步骤**：一段可复用的流程，由动作组成，比如“等画面出现 → 找到‘探索’ → 点它”。公共步骤（进入庭院、返回庭院等）可以被多个任务引用。
- **任务**：用户能运行的东西，由若干步骤组成，可以有设置项（单选、数值、文本等）。
- **版本**：每次发布是一个版本，带摘要；设备按摘要确认内容没被改过。

每个观察类的步骤都要以“核对”结束：确认画面到了预期状态，才算这一步完成。认不出就停下，不会盲目往下点。

护肝宝的代码在 [GitHub](https://github.com/lc-cn/hgb) 开源；任务包随任务版本发布后也会放在那里，谁都能看它会点哪里。
