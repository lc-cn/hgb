## 支持的任务

| 任务 | 做什么 | 设置 | 状态 |
| --- | --- | --- | --- |
| 领取每日礼包 | 启动游戏进入庭院，到商店礼包屋的“日常”领取免费的每日礼包，再回庭院 | 无 | 已发布（v1.0.0） |
| 花合战领取 | 进入庭院；花合战有红点才去，领任务页和奖励页的“全部领取” | 花札三选一礼盒选哪一种 | 待发布 |
| 喂猫喂狗 | 进入庭院；有猫狗饿了才喂，每次一份 | 无 | 待发布 |
| 日常巡游 | 进入庭院后，依次做每日礼包、花合战（各自有红点才去）和喂猫喂狗 | 花札三选一礼盒选哪一种 | 待发布 |

任务列表以你设备上启用的任务版本为准，控制台“任务库”里能看到。接下来计划补充：邮件领取、每日抽签、好友友情点、阴阳寮签到、免费召唤、勾玉卡领取、每周签到，之后是探索、御魂等战斗类。

## 账号

识别当前账号和切号还在调试，还没随任务版本发布。调试中的做法是：识别时打开头像里的设置页，读出编号和昵称；切号时从设置页的“用户中心”退回登录界面，在“已有角色”里按游戏昵称选择。只能选游戏记住的账号。

## 常见问题

**任务停在“结果待核对”怎么办？**
看一眼游戏画面，在悬浮球里告诉护肝宝那一步“已生效”还是“没生效”。没生效会重新看画面再做这一步。

**遇到没见过的弹窗？**
护肝宝会停下来，不会乱点。手动关掉弹窗后任务会继续；如果经常出现，欢迎在 [GitHub](https://github.com/lc-cn/hgb/issues) 反馈截图。

**会用掉魂玉或勾玉吗？**
不会。凡是可能花钱的按钮，点之前都会先确认价格：

- 领取每日礼包：只在按钮写着“领取”、旁边没有勾玉价格时才点，付费礼包不碰。
- 喂猫喂狗：点“喂食”前确认价格是寿司（体力），一次只喂一份；喂完弹出没见过的确认框就停下。
- 花合战：只点“全部领取”，以及你在设置里选的三选一礼盒；默认不选，遇到礼盒就停下由你处理。
