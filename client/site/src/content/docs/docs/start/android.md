| 权限 | 用来做什么 | 不开会怎样 |
| --- | --- | --- |
| 无障碍 | 看屏幕上的画面、点按钮；游戏上方的悬浮球也靠它显示 | 任务停在“等待无障碍连接”，打开后自动继续 |
| 通知 | 弹出任务提示和“本机通知”渠道的消息 | 不弹通知，网页上照样能看到 |

## 别让系统杀掉护肝宝

国产系统常会在后台清理应用。建议在系统设置里：

- 把护肝宝加入电池优化的“不优化”或“允许后台运行”名单；
- 在最近任务里锁定护肝宝；
- 关闭针对护肝宝的“自动清理”。

各品牌的入口不同，以你手机的设置为准。

## 运行时手机要怎样

任务运行时游戏需要在前台。游戏被切到后台、屏幕熄灭或无障碍断开时，任务会停下等待，恢复后继续；持续一分钟以上，打开了“运行条件中断”规则的话会通知你。
