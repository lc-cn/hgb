| 权限 | 用来做什么 | 不开会怎样 |
| --- | --- | --- |
| 无障碍 | 看屏幕上的画面、点按钮；游戏上方的悬浮球也靠它显示 | 任务停在“等待无障碍连接”，打开后自动继续 |
| 通知 | 弹出任务提示和“本机通知”渠道的消息 | 不弹通知，网页上照样能看到 |

## 别让系统杀掉护肝宝

国产系统常会在后台清理应用。建议在系统设置里：

- 把护肝宝加入电池优化的“不优化”或“允许后台运行”名单；
- 在最近任务里锁定护肝宝；
- 关闭针对护肝宝的“自动清理”。

各品牌的入口不同，以你手机的设置为准。

## 让计划到点自己跑：待命

在“我的 → 本机”打开“待命”：

- 护肝宝常驻后台，保持和服务器的连接，通知栏有一条“护肝宝待命中”。
- 打开后会多一行“后台运行”，点“去允许”在系统对话框里确认，夜里手机休眠也不会断线。
- **插着电时**，屏幕保持常亮、不会锁屏，到点直接运行。2 分钟没操作会盖上全黑屏保，只有一行暗字缓慢换位置，OLED 屏不会烧屏；点一下收起，任务开始时自动收起。
- **没插电时**，屏幕照常熄灭、锁屏。到点时如果锁着屏，任务停在“等待解锁手机”，你解锁后自动继续。

安卓不允许任何 App 解开带密码、指纹或人脸的锁屏，所以想完全无人值守，就在跑任务的时段让手机插着电。插着电时如果你手动按了锁屏，到点同样要等你解锁。

## 运行时手机要怎样

任务运行时游戏需要在前台。游戏被切到后台、屏幕熄灭、停在锁屏或无障碍断开时，任务会停下等待，恢复后继续；持续一分钟以上，打开了“运行条件中断”规则的话会通知你。
