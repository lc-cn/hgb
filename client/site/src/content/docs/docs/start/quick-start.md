## 1. 安装并登录

安卓 APK 还没有正式发布，发布后会在[首页](/#download)提供下载。安装后打开“云端控制”，填服务器地址，用邮箱和密码（或邮箱验证码）登录，这台手机会自动出现在[网页控制台](/console/)的“设备”里。网页控制台还可以用 GitHub 登录。

第一次运行任务前，按 App 的提示打开**无障碍**等权限，护肝宝靠它们看画面、点按钮。见[安卓：权限和保活](/docs/start/android/)。

:::note
护肝宝不需要 Root，也不会问你的游戏密码。
:::

## 2. 保存游戏账号

在[网页控制台](/console/)的“游戏账号”里添加，填名称（比如“主号”）、游戏里的编号和游戏昵称。有几个号就加几个。

游戏支持识别账号时，App 的“云端控制”页会出现 **识别** 按钮：在游戏里登录要用的账号后点它，护肝宝读出编号和昵称，再点 **保存** 就以游戏昵称为名保存。网页设备卡片上也能看到识别出的账号，并可以起名保存。阴阳师的识别还在调试。

切号要用到编号和游戏昵称这两项。

## 3. 设一个计划

打开[控制台](/console/) → 游戏账号 → 选一个账号 → 计划，选好任务、星期几和几点开始。到点后服务端会把任务交给登录着这个账号的设备；没有的话，找一台空闲、能切号的设备先切号再跑。

想马上试一次，就在账号的“任务与设置”里点任务旁边的 **立即运行**。

## 4. 打开通知

在控制台的“通知 · 规则”里打开你关心的规则，比如“连续执行失败”“结果待核对”；再到“通知 · 渠道”添加钉钉、企业微信、Bark、邮件、Webhook 或本机通知。详见[通知和渠道](/docs/use/notices/)。
