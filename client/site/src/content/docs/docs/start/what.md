护肝宝替你在游戏里点按钮：它看手机屏幕，认出画面，再按任务的步骤去点。它不改游戏，也不需要 Root。

## 几个概念

| 名称 | 是什么 |
| --- | --- |
| 护肝宝账号 | 你登录护肝宝用的账号。网页控制台可以用邮箱或 GitHub 登录，App 用邮箱登录；两边是同一个账号。 |
| 设备 | 装了护肝宝并登录的手机。以后 Windows 电脑也算。 |
| 应用 | 设备上的一个游戏。手机上一个游戏通常就是一个应用。 |
| 游戏账号 | 你在游戏里的账号，比如“主号”“小号”。任务设置、计划和运行记录都属于游戏账号，不属于某台设备。 |
| 任务 | 一件要做的事，比如“日常巡游”。任务由一个个步骤组成，有的任务有设置项。 |
| 计划 | 某个游戏账号每天（或每周几）几点要跑哪些任务。 |

## 它怎么替你跑

1. 计划到点（或你在网页上点“立即运行”）时，服务端为这个游戏账号找一个应用：先找正登录着这个账号的；没有就找一个空闲、能切号的。
2. 设备收到任务后，先核对游戏里登录的是不是这个账号；游戏支持切号的，不是就先切过去，核对编号对上才开始（阴阳师的识别和切号还在调试）。
3. 每一步都要认出画面再点；认不出、或者遇到没见过的弹窗，就停下来等你，不会乱点。
4. 跑完把结果上报，网页上能看到每一步，打开了通知规则的还会推送给你。

## 它不会做的事

- 不问、不保存游戏密码。切号只从游戏自己记住的账号里选。
- 没法确认结果时不假装成功，会标成“结果待核对”。
